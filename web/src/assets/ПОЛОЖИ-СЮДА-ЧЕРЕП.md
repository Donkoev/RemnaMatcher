# Арт для заставки «Красной комнаты»

Сохрани картинку с черепом в эту папку под именем:

```
redroom-skull.png
```

(подойдут также .jpg / .jpeg / .webp — главное, чтобы имя файла было `redroom-skull`)

Заставка входа подхватит её сама: dev-сервер — сразу, прод — после пересборки.
Пока файла нет, показывается запасной векторный череп.

Лучше всего смотрится картинка с тёмным/чёрным фоном — она бесшовно сольётся с заставкой.
